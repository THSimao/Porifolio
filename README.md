# Portfólio Kali — Arthur Simão

Portfólio pessoal em formato de área de trabalho inspirada no Kali Linux, com animações de janelas inspiradas no macOS.

A janela GitHub apresenta os 5 repositórios públicos de [THSimao](https://github.com/THSimao), com acesso ao código e às demonstrações publicadas.

## Abrir no VS Code

1. Abra esta pasta no VS Code.
2. Abra `index.html` com a extensão Live Server, ou execute `python -m http.server 5500` no terminal.
3. Acesse `http://localhost:5500` no navegador.

Também é possível abrir `index.html` diretamente com um navegador.

## Arquivos

- `index.html`: estrutura e conteúdo do portfólio.
- `styles.css`: visual Kali, responsividade e animações.
- `app.js`: janelas, dock, atalhos e interações.
- `assets/kali-net-wallpaper.jpg`: wallpaper principal do Kali Linux usado na área de trabalho.
- `assets/Curriculo_Arthur_Felix_Final.pdf`: currículo atualizado disponível para abrir ou baixar pelo portfólio.

## Atalhos

- Duplo clique nos ícones da área de trabalho para abrir.
- Clique nos ícones do dock para abrir ou restaurar.
- Duplo clique na barra de título para maximizar/restaurar.
- `Esc` fecha a janela ativa.
- `Ctrl + Alt + T` abre o terminal, como no Kali/Xfce.
- `/` abre o menu do Kali e posiciona o cursor na pesquisa.

## Elementos inspirados no Kali

- Prompt característico `arthur㉿kali` no terminal.
- Menu de aplicativos com categorias oficiais do ecossistema Kali.
- Central visual “Kali Tools”, sem execução de comandos.
- Controles de janela no estilo Xfce e alternador de áreas de trabalho.
